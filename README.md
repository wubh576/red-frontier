# 赤色前线 · Red Frontier

一个受经典即时战略游戏启发的原创简化版网页 RTS，目标是直接在浏览器中离线游玩。

## 当前状态

项目处于初始界面搭建阶段，**尚不可游玩**。

- `index.html`：战场、建造面板和任务介绍的界面骨架。
- `style.css`：界面样式。
- HTML 中引用的 `engine.js` 和 `game.js` 尚未实现，将在后续功能开发中补齐。

## 计划玩法

- 采矿和资金管理。
- 基地建设、电力管理、部队生产。
- 框选部队、移动和攻击。
- 单人电脑对战及本地存档。

## 开发约定

- 远端仓库：https://github.com/wubh576/red-frontier
- `main` 保存已提交的开发基线；初始基线仅包含界面骨架。
- 后续功能在 `codex/` 前缀的分支开发，按可验证的功能阶段提交。
- 游戏运行不依赖联网或远程资源。

目前可双击 `index.html` 预览静态界面，操作按钮需等待游戏逻辑实现。
