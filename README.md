# 赤色前线 · Red Frontier

一个受经典即时战略游戏启发的原创网页 RTS。单人对战电脑，画面、地图和音效均在本地生成，无第三方运行依赖，不需要联网。

## 开始游戏

### 直接打开

双击 `index.html`，在桌面浏览器里点击「开始行动」。请保留项目的完整目录结构，页面会读取 `src/` 和 `styles/` 下的文件。

### 本地 Web 服务

安装 Node.js 18 或以上版本后，在项目目录运行：

```sh
npm start
```

访问 **http://127.0.0.1:8765**。不需要运行 `npm install`。服务只监听本机；终端按 `Ctrl+C` 停止。如果端口被占用，可以使用 `PORT=8766 npm start`（macOS / Linux）。

**每局都是新开的。** 开局可选择简单、标准、困难；地图种子留空时，每局生成新的地形、道路和矿区。填相同种子可重玩相同地图。页面刷新后回到任务介绍，点击「重新开始」可调整难度并重置战局。没有账号、云服务或本地存档。暂停只保留当前页面里的战局，切换标签页或窗口失去焦点时会自动暂停。

## 项目结构

```text
red-frontier/
├── index.html            # 游戏入口
├── src/
│   ├── engine.js         # 纯模拟：地图、寻路、经济、战斗和电脑对手
│   └── game.js           # Canvas 绘制、输入、镜头和界面流程
├── styles/
│   └── game.css          # 页面与面板样式
├── scripts/
│   └── server.js         # 仅监听本机的静态服务
├── tests/
│   ├── engine.test.js    # 基础玩法与建筑队列测试
│   └── skirmish.test.js  # 随机地图、步兵与难度测试
├── docs/
│   └── gameplay.md      # 玩法、单位数值和操作说明
├── package.json          # 启动与验证命令
└── README.md             # 项目入口文档
```

详细玩法见 [玩法与操作](docs/gameplay.md)。

## 开发与验证

```sh
npm run check
npm test
```

模拟逻辑在 `src/engine.js`，不依赖 DOM；界面与输入在 `src/game.js`。修改游戏规则时同步维护 `tests/` 和玩法文档。`scripts/server.js` 仅提供游戏入口、两个脚本和样式文件，不对外提供源码目录列表、测试或文档。

运行时只有静态文件，不使用包下载、CDN、外部字体、图片或接口。使用有种子的随机地图和固定步长模拟，便于重现问题。27 项模拟测试包含 300 个地图种子的矿区、基地出口、开局单位通行检查。设计面向桌面浏览器和鼠标，不提供移动端触控操作。

当前是基础遭遇战版本：简化原创图形、随机地图、两种步兵和三个电脑难度；尚未实现海空军、科技树、联机或战役。交火使用距离判定，未实现弹道遮挡。
