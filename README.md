# 赤色前线 · Red Frontier

一个受经典即时战略游戏启发的原创网页 RTS。单人对战电脑，画面、地图和音效均在本地生成，无第三方运行依赖，不需要联网。

## 开始游戏

### 直接打开

双击 `index.html`，在桌面浏览器里点击「开始行动」。保留同目录下的 `style.css`、`engine.js` 和 `game.js`。

### 本地 Web 服务

安装 Node.js 18 或以上版本后，在项目目录运行：

```sh
npm start
```

访问 **http://127.0.0.1:8765**。不需要运行 `npm install`。服务只监听本机；终端按 `Ctrl+C` 停止。如果端口被占用，可以使用 `PORT=8766 npm start`（macOS / Linux）。

**每局都是新开的。** 页面刷新后回到任务介绍，点击「重新开始」会重置当前战局。没有账号、云服务或本地存档。暂停只保留当前页面里的战局，切换标签页或窗口失去焦点时会自动暂停。

## 一局怎么玩

1. 开局有指挥部、发电厂、精炼厂、1 辆矿车和 2 辆坦克，资金为 $2,400。
2. 矿车自动采矿，每次装满 300 矿石后运回精炼厂换成资金，矿藏会耗尽。
3. 点击「战车工厂」，等待 12 秒，点击「部署」，在已有基地附近的空地放置。
4. 切到「部队生产」，排队制造主战坦克、侦察车或矿车。单位队列最多 8 辆，我方部队上限为 60 辆。
5. 防御电脑的进攻，集结部队向东北推进。摧毁敌方指挥部获胜；自己的指挥部被摧毁则失败。

首波敌军在第 85 秒出动，随后每隔 55 秒组织进攻。电脑同样采矿和花钱造兵；摧毁其矿车、精炼厂或工厂可以削弱增援。

### 建筑与单位

| 对象       |   价格 | 施工 / 生产时间 | 作用                                  |
| ---------- | -----: | --------------: | ------------------------------------- |
| 发电厂     |   $500 |            9 秒 | 提供 150 电力                         |
| 矿石精炼厂 | $1,000 |           14 秒 | 耗电 30，接收矿石，部署时附赠一辆矿车 |
| 战车工厂   |   $900 |           12 秒 | 耗电 70，解锁战车生产                 |
| 防御炮塔   |   $450 |            8 秒 | 耗电 30，自动攻击范围内敌军           |
| 主战坦克   |   $450 |            8 秒 | 主力装甲单位                          |
| 侦察战车   |   $250 |            5 秒 | 速度快、视野大、装甲较薄              |
| 采矿车     |   $650 |           10 秒 | 自动采矿，无攻击能力                  |

电力显示为「供电 / 用电」。供电不足时施工和生产速度降为 35%，防御炮塔停火。工厂被摧毁时单位生产暂停，重建后继续。点击队列里的 `×` 取消项目并全额退款。施工与战车生产各使用一个共享队列，多座工厂不会叠加生产速度。

## 操作

| 操作                     | 按键                           |
| ------------------------ | ------------------------------ |
| 单选 / 框选              | 左键点击 / 拖动                |
| 增选或移除选择           | Shift + 左键；Shift + 拖动增选 |
| 选择视野内同类单位       | 双击单位                       |
| 移动 / 攻击指定敌军      | 右键地面 / 可见敌军            |
| 指定矿区                 | 选矿车，右键矿藏               |
| 攻击推进，沿途自动交战   | A，再左键目标位置              |
| 全选战斗部队（不含矿车） | Q                              |
| 停止 / 原地警戒          | S                              |
| 回到基地                 | H                              |
| 平移视角                 | 方向键 / 鼠标中键拖动          |
| 快速定位                 | 点击小地图                     |
| 缩放                     | 滚轮 / 战场右下角 `+` `−`      |
| 暂停 / 继续              | 空格 / 顶栏按钮                |
| 取消部署或攻击指令模式   | Esc / 右键                     |

点击右上角 `?` 可查看指挥手册。音效默认关闭，可在战场顶部开启。

## 开发与验证

```sh
npm run check
npm test
```

- `engine.js`：与界面无关的模拟，包括地图、A\* 寻路、采矿、建造、生产、战斗、战争迷雾和电脑对手。
- `game.js`：Canvas 绘制、鼠标键盘交互、镜头、面板、暂停及新局流程。
- `index.html` / `style.css`：界面结构与样式。
- `server.js`：可选的本地静态服务，只提供游戏所需的四个文件。
- `tests/engine.test.js`：使用 Node.js 自带测试工具验证关键玩法。

运行时只有静态文件，不使用包下载、CDN、外部字体、图片或接口。使用固定地图和固定步长模拟，便于重现问题。设计面向桌面浏览器和鼠标，不提供移动端触控操作。

当前是基础遭遇战版本：简化原创图形、单张地图、单种电脑难度；尚未实现步兵、海空军、科技树、联机或战役。交火使用距离判定，未实现弹道遮挡。
