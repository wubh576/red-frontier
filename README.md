# 赤色前线 · Red Frontier

一个受经典即时战略游戏启发的原创网页 RTS。单人对战电脑，画面、地图和音效均在本地生成，无第三方运行依赖，不需要联网。

## 开始游戏

### 直接打开

双击 `index.html`，在桌面浏览器里点击「开始行动」。保留同目录下的 `style.css`、`engine.js` 和 `game.js`。

### 本地 Web 服务

安装 Node.js 18 或以上版本后，在项目目录运行：

```sh
npm start
```

访问 **http://127.0.0.1:8765**。不需要运行 `npm install`。服务只监听本机；终端按 `Ctrl+C` 停止。如果端口被占用，可以使用 `PORT=8766 npm start`（macOS / Linux）。

**每局都是新开的。** 开局可选择简单、标准、困难；地图种子留空时，每局生成新的地形、道路和矿区。填相同种子可重玩相同地图。页面刷新后回到任务介绍，点击「重新开始」可调整难度并重置战局。没有账号、云服务或本地存档。暂停只保留当前页面里的战局，切换标签页或窗口失去焦点时会自动暂停。

## 一局怎么玩

1. 开局有指挥部、发电厂、精炼厂、1 辆矿车和 2 辆坦克，标准难度资金为 $2,400。
2. 矿车自动采矿，每次装满 300 矿石后运回精炼厂换成资金，矿藏会耗尽。
3. 点击「兵营」（7 秒）或「战车工厂」（12 秒），完成后点击「部署」，在已有基地附近的空地放置。
4. 切到「部队生产」：兵营训练步枪兵、反坦克兵；战车工厂制造坦克、侦察车、矿车。步兵和战车可以同时生产，分别最多排队 12 人和 8 辆，共享 60 个单位上限。
5. 防御电脑的进攻，集结部队向东北推进。摧毁敌方指挥部获胜；自己的指挥部被摧毁则失败。

### 随机性与难度

| 难度 | 我方初始资金 | 首波出动 | 后续进攻间隔 | 敌军生产基础间隔 |
| ---- | -----------: | -------: | -----------: | ---------------: |
| 简单 |       $3,200 |   120 秒 |     60–80 秒 |            17 秒 |
| 标准 |       $2,400 |    85 秒 |     47–63 秒 |            12 秒 |
| 困难 |       $2,000 |    60 秒 |     34–46 秒 |             8 秒 |

每局随机生成山脊、道路和五处矿藏的位置与储量。基地位置保持左下 / 右上，双方初始矿区储量相同。生成器保留基地空地、连接矿区，并修通孤立地块，避免开局无路可走。

敌军的兵种组合、每波目标和后续出动时间会变化；生产基础间隔上下浮动 15%，低电力还会减速。较高难度下敌军初始资金、部队上限和出兵规模也更高，双方同种单位的生命值和伤害一致。电脑会采矿和花钱造兵；摧毁其矿车、精炼厂、工厂或兵营可以削弱增援。

种子为 0–4294967295 的整数，当前种子显示在战场左上角。**同一版本、相同种子会生成同一地图**，切换难度不会改变地图。相同难度、相同种子和相同操作可以复现模拟；改变操作自然会改变战局。种子留空时才会在每次开局重新随机。

### 建筑与单位

| 对象       |   价格 | 施工 / 生产时间 | 作用                                  |
| ---------- | -----: | --------------: | ------------------------------------- |
| 发电厂     |   $500 |            9 秒 | 提供 150 电力                         |
| 矿石精炼厂 | $1,000 |           14 秒 | 耗电 30，接收矿石，部署时附赠一辆矿车 |
| 兵营       |   $400 |            7 秒 | 耗电 20，解锁两种步兵                 |
| 战车工厂   |   $900 |           12 秒 | 耗电 70，解锁战车生产                 |
| 防御炮塔   |   $450 |            8 秒 | 耗电 30，自动攻击范围内敌军           |
| 步枪兵     |   $100 |            3 秒 | 对步兵效果好，打装甲和建筑较弱        |
| 反坦克兵   |   $220 |            5 秒 | 远距离反装甲，射速慢、对步兵较弱      |
| 主战坦克   |   $450 |            8 秒 | 主力装甲单位                          |
| 侦察战车   |   $250 |            5 秒 | 速度快、视野大、装甲较薄              |
| 采矿车     |   $650 |           10 秒 | 自动采矿，无攻击能力                  |

电力显示为「供电 / 用电」。供电不足时施工和生产速度降为 35%，防御炮塔停火。工厂或兵营被摧毁时，其对应队列暂停，重建后继续。点击队列里的 `×` 取消项目并全额退款。施工、战车生产、步兵训练各使用一个独立队列，多座同类生产建筑不会叠加生产速度。

## 操作

| 操作                     | 按键                           |
| ------------------------ | ------------------------------ |
| 单选 / 框选              | 左键点击 / 拖动                |
| 增选或移除选择           | Shift + 左键；Shift + 拖动增选 |
| 选择视野内同类单位       | 双击单位                       |
| 移动 / 攻击指定敌军      | 右键地面 / 可见敌军            |
| 指定矿区                 | 选矿车，右键矿藏               |
| 攻击推进，沿途自动交战   | A，再左键目标位置              |
| 全选战斗部队（不含矿车） | Q                              |
| 停止 / 原地警戒          | S                              |
| 回到基地                 | H                              |
| 平移视角                 | 方向键 / 鼠标中键拖动          |
| 快速定位                 | 点击小地图                     |
| 缩放                     | 滚轮 / 战场右下角 `+` `−`      |
| 暂停 / 继续              | 空格 / 顶栏按钮                |
| 取消部署或攻击指令模式   | Esc / 右键                     |

点击右上角 `?` 可查看指挥手册。音效默认关闭，可在战场顶部开启。

## 开发与验证

```sh
npm run check
npm test
```

- `engine.js`：与界面无关的模拟，包括地图、A\* 寻路、采矿、建造、生产、战斗、战争迷雾和电脑对手。
- `game.js`：Canvas 绘制、鼠标键盘交互、镜头、面板、暂停及新局流程。
- `index.html` / `style.css`：界面结构与样式。
- `server.js`：可选的本地静态服务，只提供游戏所需的四个文件。
- `tests/engine.test.js`：使用 Node.js 自带测试工具验证关键玩法。

运行时只有静态文件，不使用包下载、CDN、外部字体、图片或接口。使用有种子的随机地图和固定步长模拟，便于重现问题。23 项模拟测试包含 300 个地图种子的矿区、基地出口、开局单位通行检查。设计面向桌面浏览器和鼠标，不提供移动端触控操作。

当前是基础遭遇战版本：简化原创图形、随机地图、两种步兵和三个电脑难度；尚未实现海空军、科技树、联机或战役。交火使用距离判定，未实现弹道遮挡。
